Para executar:
```
1. unzip no mnist-in-csv, que é a base de dados
2. instalar os modulos do requirements.txt via uv ou pip
3. python main.py (path do arquivo de treino) (path do arquivo de teste)
```
se os arquivos de treino e teste estiverem na mesma pasta que `main.py`, com os nomes originais de `mnist_train.csv` e `mnist_test.csv`, os caminhos serão utilizados automaticamente.:wq
